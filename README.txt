PROYECTO 18 - VARIANTE B: PEAJE
Abrir esta carpeta desde CLion. CMake detectará CMakeLists.txt.
Compilar y ejecutar el target Proyecto18_Peaje.
El programa utiliza C++17 y archivos de texto. El archivo peaje_datos.txt se crea
en el directorio de ejecución al guardar o salir.
Tarifas iniciales de ejemplo: motocicleta Q10, automóvil Q20, transporte pesado Q35.
Estas tarifas son configurables desde el menú y deben ajustarse si el docente
establece otros valores.
